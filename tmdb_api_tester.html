⚠️ Gevonden problemen in jouw script
  • Je gebruikt now_playing & on_the_air — dit zijn populariteitslijsten zonder exacte uitzenddatum per platform. Ze geven je welke films/series beschikbaar zijn, niet wanneer ze nieuw verschijnen op een streamer.
  • Geen primary_release_date filter — je filtert niet op de datum dat iets op een platform verschijnt, alleen op of het er staat.
  • Max 15 items per provider — je pakt alleen de eerste 15 resultaten van on_the_air, terwijl FilmVandaag vermoedelijk discover gebruikt met with_release_type=4 (streaming) per datum.
  • Geen release_dates endpoint — voor films is er een apart endpoint dat precies aangeeft wanneer een film op een NL platform verschijnt.

📋 Aanbevolen implementatie voor Streamgids
  • Gebruik /discover/movie met with_release_type=4 (digitale streaming) en primary_release_date.gte/lte om films te vinden die in een datumvenster nieuw op streaming zijn.
  • Gebruik /discover/tv met air_date.gte/lte en with_watch_providers voor series-afleveringen.
  • Loop door alle NL provider IDs (8=Netflix, 119=Prime, 337=Disney+, etc.) en doe per provider een discover-call — dan weet je exact welke titels per platform beschikbaar zijn voor welke datum.
  • Gebruik /movie/{id}/release_dates voor de exacte NL streaming-datum van individuele films (type 4 = digital).
  • Gebruik /tv/{id}/season/{n}/episode/{n} voor de exacte air_date van een aflevering in NL.
// Betere aanpak voor fetchTMDBReleases()
// Stap 1: haal provider IDs op
tmdb('/watch/providers/movie', {watch_region:'NL'})

// Stap 2: per provider, discover films die nieuw zijn
tmdb('/discover/movie', {
  with_watch_providers: '8', // Netflix
  watch_region: 'NL',
  with_release_type: '4', // 4 = digitaal/streaming
  'primary_release_date.gte': '2025-03-01',
  'primary_release_date.lte': '2025-04-15',
  sort_by: 'primary_release_date.desc',
  language: 'nl-NL'
})

// Stap 3: voor TV, gebruik air_date filters
tmdb('/discover/tv', {
  with_watch_providers: '8',
  watch_region: 'NL',
  'air_date.gte': '2025-03-01',
  'air_date.lte': '2025-04-15',
  sort_by: 'first_air_date.desc',
  language: 'nl-NL'
})
